# Onboard to demo-ai-app

1. Read root AGENTS.md and .cursor/knowledge/repository-profile.md.
2. Locate the owning module in .cursor/knowledge/module-index.md.
3. Read its nearest module profile, manifests, source, tests, contracts, CI, and callers.
4. State purpose, boundaries, selected profiles, canonical commands, security/tenant concerns, and uncertainties.
5. Do not edit until ownership and verification are clear.
